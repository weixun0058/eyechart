# Android-only 可跟踪任务清单

## 使用规则
- 状态仅允许：`todo` / `doing` / `blocked` / `done`
- 每次状态变化都要更新“最后更新时间”和“证据”
- 证据必须可回溯：命令、输出摘要、文件路径、截图编号
- 若任务阻塞，必须在“阻塞原因”写明下一步解法
