## 后续步骤

### 需要用户执行的操作

1. **安装 Flutter SDK**
   ```bash
   # 下载并安装 Flutter SDK
   # 添加到系统 PATH
   ```

2. **获取依赖**
   ```bash
   flutter pub get
   ```

3. **生成代码**
   ```bash
   flutter pub run build_runner build --delete-conflicting-outputs
   ```

4. **运行测试**
   ```bash
   flutter test
   ```

5. **运行应用**
   ```bash
   flutter run -d windows
   ```
